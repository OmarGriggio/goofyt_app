# frontend-polloshermanos
frontend-polloshermanos created by GitHub Classroom

--Description du projet

notre projet est une application de fitness et de bien être qui permet les fonctionnalités suivantes :

- Permettre à l'utilisateur de créer son programme d'entrainement.
- Suivre sa progression et ses performances.
- Chercher des exercices et comprendre comment les faires (avec des vidéos explicatives).
- Gérer son compte personnel.


--Qui sont les potentiels clients / personas de votre application?

les clients sont les personnes qui font du sport dans une salle de fitness ainsi que les salles de sport qui peuvent mettre en place des programmes pré fait pour leurs clients.
		
--Quels sont les besoin du client (jobs, pain, gains).

- s'informer sur l'exuction d'un exercice.
- créer son programme d'entrainement et d'avoir un suivi de celui-ci
- évite au client de devoir chercher par lui-même, cela prend du temps et c'est vite démoralisant.
		
--Comment votre solution va y répondre (à travers quelles fonctionnalités).
- Scanner un code QR d'une machine permet au client d'avoir une description des exercices qui peuvent être effectués sur cette machine et des vidéos explicatives.
- il peut analyser ces statistiques via des graphiques.
